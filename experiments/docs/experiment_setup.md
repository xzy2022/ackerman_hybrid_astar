# 实验 A-01: Hybrid A* 算法批量性能评估

## 4. 碰撞检测模型对比

本实验的核心在于对比两种碰撞检测模型：

### 4.1 规划时使用：圆形近似模型
- **方法**: 沿车身纵向分布多个圆（默认5个）
- **检查**: 圆心所在的栅格是否为障碍物
- **优点**: 快速，适合实时规划
- **缺点**: 可能存在精度不足（角点、边缘）

实现位置：`src/grid_map.py::GridMap.check_collision()`

### 4.2 验证时使用：多边形精确检测
- **方法**: 使用 Shapely 库进行栅格-多边形相交检测
- **检查**: 整个车辆多边形是否与障碍物栅格相交
- **优点**: 精确，可作为 Ground Truth
- **缺点**: 计算量较大

实现位置：`src/grid_map.py::GridMap.check_strict_path_collision()`

### 4.3 安全违规 (Safety Violation)
当规划结果显示"成功"，但严格检测发现碰撞时，称为**安全违规**。

这个指标非常重要，因为它反映了：
- 圆形近似模型是否足够保守
- 是否存在漏检风险（规划认为安全，实际不安全）

- 预期平均时间: **100-500ms**
- 取决于地图复杂度和启发式权重

### 8.3 安全违规率
- **关键指标**: 圆形近似的精度评估
- 预期违规率: **0-10%**
  - 0%: 圆形模型非常保守，可能过度限制搜索空间
  - 5-10%: 可接受范围（轻微精度损失）
  - >20%: 圆形模型精度不足，需要增加圆的数量或半径
